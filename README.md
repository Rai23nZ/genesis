# Семейный архив — автономная версия для собственного сервера

## Состав
- `index.html` — точка входа
- `app.js` — приложение (React, без сборки)
- `family-data.js` — данные семьи + импорт/экспорт/раскладка древа
- `world-map.js` — веб-компонент карты `<family-map>`
- `styles.css` — дизайн-система (шрифты, цвета, компоненты)

## Деплой
Никакой сборки не требуется. Скопируйте всю папку `export/` на сервер как есть и раздавайте статикой (nginx, Apache, Caddy, S3+CloudFront, GitHub Pages и т.п.).

Важно: страница использует ES-модули (`import`), поэтому её нужно открывать **через http(s)://**, не через `file://` — иначе браузер блокирует импорт по CORS. Любой обычный веб-сервер подходит.

Минимальный пример на nginx:
```
server {
  listen 80;
  server_name archive.example.com;
  root /var/www/family-archive;
  index index.html;
}
```

Или локально для проверки:
```
npx serve export/
# или
python3 -m http.server --directory export 8080
```

## Данные
Сейчас в `family-data.js` — демонстрационные данные (50 человек рода Ковалёвых/Ланских). Чтобы загрузить свою семью:
- через интерфейс: кнопка «Импорт» → файл `.json` или `.ged` (GEDCOM); название архива подтягивается из `title` в JSON или строки `1 FILE` в блоке `HEAD` GEDCOM;
- или замените содержимое `family-data.js` напрямую (массив `PEOPLE`, координаты городов в `PLACES`).

Изменения, сделанные в браузере (импорт, правки, фото), хранятся в памяти вкладки и заменяются при перезагрузке — на этом этапе прототип без базы данных и сервера. Экспорт («Печать» не входит — только «Экспорт») сохраняет бэкап `.json` с людьми, очередью модерации и названием.
